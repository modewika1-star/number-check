# NumberCheck | Compare with 100

[![Live Demo](https://img.shields.io/badge/Live_Demo-Open_Project-2563EB?style=for-the-badge&logo=vercel&logoColor=white)](https://number-100-comparator-2-mjs.vercel.app/)

A beginner JavaScript exercise that compares a user-entered number with 100 and displays the result.

## ✨ Logic

- If the number equals 100, the page displays **equal to 100**.
- If the number is less than 100, the page displays **less than 100**.
- Otherwise, the page displays **more than 100**.
- The result is also written to the browser console.

## 🛠️ Built with

- HTML5
- JavaScript
- Conditional statements

## ▶️ Run locally

~~~bash
git clone https://github.com/modewika1-star/t9.git
cd t9
~~~

Open `index.html`, enter a number, and click **Check**.

## 📁 Files

- `index.html`: numeric input and result area.
- `script1.js`: comparison logic.
